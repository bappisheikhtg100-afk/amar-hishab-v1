আমার হিসাব — প্রজেক্ট ফাইল ডাউনলোড

নিচের বাটনে ক্লিক করলে ফাইল ভেরিফাই হয়ে সরাসরি আপনার ডিভাইসে ডাউনলোড হবে (কোনো করাপ্টেড ফাইল হবে না)।

1. GitHub Auto-APK Capacitor Project (.zip)

আনজিপ করে GitHub Repository-তে আপলোড করলেই GitHub Actions অটোমেটিক অফলাইন amar-hisab.apk তৈরি করে দেবে।

2. Full Demo Data File (.json)

অ্যাপের ভেতর সেটিংস → ডাটা রিস্টোর / ইমপোর্ট এ গিয়ে এই ফাইলটি সিলেক্ট করলে ৩ মাসের আয়-ব্যয়, দেনা-পাওনা, বাজেট, রিমাইন্ডার, সঞ্চয় ও কন্টাক্ট লোড হবে।
